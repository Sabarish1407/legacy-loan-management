# Database Schema & Migrations

## 1. Overview

The database uses PostgreSQL for runtime/development and H2 (PostgreSQL compatibility mode) for automated tests. All schema definitions, constraints, indexes, and initial data are managed through **Flyway**.

Location: `src/main/resources/db/migration`

---

## 2. Migration Files

- **`V1__init_schema.sql`**: Initial table creation, foreign keys, unique constraints, and lookup indexes.
- **`V2__sample_data.sql`**: Pre-seeded development data with sample customers and role-based application users (`admin`, `officer`, `john_doe`, `jane_smith`).

---

## 3. Entity-Relationship Model

```
customers (1) ──< loan_applications (N) ── (1) loan_accounts (1) ──< repayment_schedules (N)
     │                                                │
     └──< app_users (1)                               └──< loan_repayments (N)
                                                      │
                                                      └── (1) disbursements (1)
```

### Table Definitions

#### `customers`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `first_name`: VARCHAR(100) NOT NULL
- `last_name`: VARCHAR(100) NOT NULL
- `email`: VARCHAR(150) NOT NULL UNIQUE
- `phone`: VARCHAR(30) NOT NULL
- `national_id`: VARCHAR(50) NOT NULL UNIQUE
- `address`: VARCHAR(255) NOT NULL
- `date_of_birth`: DATE NOT NULL
- `monthly_income`: NUMERIC(15, 2) NOT NULL
- `employment_type`: VARCHAR(50) NOT NULL (`SALARIED`, `SELF_EMPLOYED`, `UNEMPLOYED`, `BUSINESS`)
- `credit_score`: INT (300-850)
- `kyc_status`: VARCHAR(30) NOT NULL (`PENDING`, `VERIFIED`, `REJECTED`)
- `created_at`, `updated_at`: TIMESTAMP

#### `app_users`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `username`: VARCHAR(50) NOT NULL UNIQUE
- `password`: VARCHAR(255) NOT NULL (BCrypt hashed)
- `role`: VARCHAR(50) NOT NULL (`ADMIN`, `LOAN_OFFICER`, `CUSTOMER`)
- `customer_id`: BIGINT REFERENCES customers(id)
- `enabled`: BOOLEAN NOT NULL DEFAULT TRUE

#### `loan_applications`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `customer_id`: BIGINT NOT NULL REFERENCES customers(id)
- `loan_type`: VARCHAR(30) NOT NULL (`PERSONAL`, `HOME`, `VEHICLE`, `EDUCATION`)
- `requested_amount`: NUMERIC(15, 2) NOT NULL
- `interest_rate`: NUMERIC(5, 2) NOT NULL
- `tenure_months`: INT NOT NULL
- `employment_type`: VARCHAR(50) NOT NULL
- `monthly_income`: NUMERIC(15, 2) NOT NULL
- `application_date`: TIMESTAMP NOT NULL
- `status`: VARCHAR(30) NOT NULL (`SUBMITTED`, `UNDER_REVIEW`, `APPROVED`, `REJECTED`, `DISBURSED`, `CLOSED`)
- `rejection_reason`: VARCHAR(500)
- `approved_amount`: NUMERIC(15, 2)
- `approved_tenure_months`: INT
- `approved_interest_rate`: NUMERIC(5, 2)
- `review_notes`: VARCHAR(1000)

#### `loan_accounts`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `application_id`: BIGINT NOT NULL UNIQUE REFERENCES loan_applications(id)
- `customer_id`: BIGINT NOT NULL REFERENCES customers(id)
- `account_number`: VARCHAR(50) NOT NULL UNIQUE
- `principal_amount`: NUMERIC(15, 2) NOT NULL
- `annual_interest_rate`: NUMERIC(5, 2) NOT NULL
- `tenure_months`: INT NOT NULL
- `monthly_emi`: NUMERIC(15, 2) NOT NULL
- `outstanding_principal`: NUMERIC(15, 2) NOT NULL
- `disbursement_date`: TIMESTAMP NOT NULL
- `status`: VARCHAR(30) NOT NULL (`ACTIVE`, `CLOSED`, `DEFAULTED`)
- `closed_at`: TIMESTAMP

#### `disbursements`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `application_id`: BIGINT NOT NULL UNIQUE REFERENCES loan_applications(id)
- `loan_account_id`: BIGINT NOT NULL UNIQUE REFERENCES loan_accounts(id)
- `amount`: NUMERIC(15, 2) NOT NULL
- `disbursement_date`: TIMESTAMP NOT NULL
- `account_number`: VARCHAR(50) NOT NULL
- `status`: VARCHAR(30) NOT NULL (`SUCCESS`, `FAILED`, `PENDING`)
- `reference_number`: VARCHAR(100) NOT NULL UNIQUE

#### `repayment_schedules`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `loan_account_id`: BIGINT NOT NULL REFERENCES loan_accounts(id)
- `installment_number`: INT NOT NULL
- `due_date`: DATE NOT NULL
- `principal_amount`: NUMERIC(15, 2) NOT NULL
- `interest_amount`: NUMERIC(15, 2) NOT NULL
- `total_emi`: NUMERIC(15, 2) NOT NULL
- `outstanding_principal`: NUMERIC(15, 2) NOT NULL
- `paid_amount`: NUMERIC(15, 2) NOT NULL DEFAULT 0.00
- `status`: VARCHAR(30) NOT NULL (`PENDING`, `PAID`, `PARTIALLY_PAID`, `OVERDUE`)
- `paid_date`: DATE
- CONSTRAINT `uk_sched_acc_inst` UNIQUE (`loan_account_id`, `installment_number`)

#### `loan_repayments`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `loan_account_id`: BIGINT NOT NULL REFERENCES loan_accounts(id)
- `payment_reference`: VARCHAR(100) NOT NULL UNIQUE
- `idempotency_key`: VARCHAR(100) NOT NULL UNIQUE
- `amount`: NUMERIC(15, 2) NOT NULL
- `payment_date`: TIMESTAMP NOT NULL
- `payment_method`: VARCHAR(50) NOT NULL
- `principal_component`: NUMERIC(15, 2) NOT NULL
- `interest_component`: NUMERIC(15, 2) NOT NULL
- `late_fee`: NUMERIC(15, 2) NOT NULL
- `status`: VARCHAR(30) NOT NULL (`SUCCESS`, `FAILED`, `PENDING`)
- `notes`: VARCHAR(500)

#### `audit_logs`
- `id`: BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- `entity_name`: VARCHAR(100) NOT NULL
- `entity_id`: VARCHAR(100) NOT NULL
- `action`: VARCHAR(100) NOT NULL
- `performed_by`: VARCHAR(100) NOT NULL
- `timestamp`: TIMESTAMP NOT NULL
- `details`: VARCHAR(1000)
- `client_ip`: VARCHAR(50)

## 4. Key Performance Indexes

- `idx_customer_email`: Index on `customers(email)`
- `idx_customer_national_id`: Index on `customers(national_id)`
- `idx_loan_app_customer`: Index on `loan_applications(customer_id)`
- `idx_loan_app_status`: Index on `loan_applications(status)`
- `idx_loan_acc_customer`: Index on `loan_accounts(customer_id)`
- `idx_loan_acc_number`: Index on `loan_accounts(account_number)`
- `idx_sched_acc_status`: Composite index on `repayment_schedules(loan_account_id, status)`
- `idx_repay_acc`: Index on `loan_repayments(loan_account_id)`
- `idx_repay_idempotency`: Index on `loan_repayments(idempotency_key)`
- `idx_audit_entity`: Composite index on `audit_logs(entity_name, entity_id)`
